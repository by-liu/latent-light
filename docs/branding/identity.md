# Identity asset provenance

Reviewed: October 2, 2026
Asset inventory updated: October 3, 2026

These assets were created through AI image generation during the local design
process. The author selected the current spectral aperture logos and galactic
line artwork. The design direction references light, discovery, a galactic
setting, and the author's interest in Pink Floyd. This is creative inspiration,
not an attribution to that band or a claim of endorsement.

The exact generation prompts for these identity assets were not preserved in
the repository. The descriptions below summarize the available project history.
They are not reconstructed prompts. No exact generation date is asserted here.
Preserve prompts and reference records for future generations.

The refined aperture is slightly elliptical rather than perfectly round.
The galaxy illustration is decorative, not an astronomical diagram.
These images are raster references, not vector masters or a cleared trademark.
The artwork in `public/brand/` and `public/favicon.ico` is excluded from the
MIT license for original code and writing. No separate reuse license is granted
for these identity assets. See the [README license section](../../README.md#license).

The current cartoon avatar has its own exact prompt and public portrait
reference in [avatar-cartoon.md](avatar-cartoon.md).
