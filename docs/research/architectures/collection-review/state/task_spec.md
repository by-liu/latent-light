No new model families, unsupported rankings, copied proprietary content, benchmark runs, dependency upgrades, commits, pushes or deployment.

Canonical Markdown audit report at report.md. Website pages are the requested implementation, not duplicates of the audit report. Short learning introductions, page-local footnotes, explicit evidence limits. Public-safe source records; no automated refresh.

## Visual contract

Skeptical direction: distinguish configured capability from tested usefulness, and implementation details from public inference.

## Budget and checkpoints

Inspect the existing source set in bounded mechanism and model passes. Perform a separate adversarial pass. Stop when current scope is accurately explained and validated. No subagents.

## Success criteria

All ten pages reviewed and materially refined; claims sourced, math typeset and numbered, useful figures readable, exports meaningful, full validation successful. Preserve unrelated work and report existing warnings.

## Assumptions and decisions
