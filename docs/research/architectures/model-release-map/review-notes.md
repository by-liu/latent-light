# Release map review

## Source and date audit

The release map deliberately mixes dated papers, announcements, previews and
weights releases. Each entry records its event type and a primary source.
The map does not assert that these are all the important models, that every
model was generally available at launch, or that chronology implies lineage.

T5 uses its 2019 preprint, not its 2020 journal date. GPT-2 uses its initial
staged release. BLOOM uses its July weights release, not its November report.
InstructGPT uses its 2022 alignment announcement, not the earlier beta.
Qwen2-VL retains the August 29 announcement versus August 30 repository
release distinction. Qwen3-VL and the Qwen3.5 and Qwen3.8 families use their
first specified checkpoint releases. Kimi K3 uses weights and report release.
Gemini 4 Argon is explicitly a restricted rollout.

The name and event ledger contains 38 records sorted by event date. The public
page cites each entry beside its name, with date and event details available
on demand. There are no architecture diagrams or training recipes on this
page, and no archival paper figure reuse.
