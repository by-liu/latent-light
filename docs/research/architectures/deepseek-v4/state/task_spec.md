# DeepSeek-V4 study contract

## Primary question

How do compressed attention, hyper-connections and conditional memory change
DeepSeek-V4, and what do its public report and artifacts establish?

## Intended reader and use

Technical readers studying efficient LLM architectures. Connect long context
mechanisms to cache, computation, training and serving tradeoffs.

## Scope and time boundary

The original preview report and DeepSeek-V4-Flash artifact. Separate Pro and
later 0731/0813 releases. Evidence checked October 10, 2026.

## Exclusions

No model downloads, runtime experiments, private material, unlicensed source art,
unconditional leaderboard rankings, or deployment recommendations.

## Deliverables

Canonical report.md, clean website MDX, source and claim ledgers, run history,
and a numbered original architecture diagram with a text equivalent.

## Report contract

Use the Model Deep Dive guide, claim-local footnotes, explicit scale and
variant boundaries. Public-safe records; no automatic refresh, commit or deploy.

## Visual contract

One original responsive diagram distinguishes local, compressed sparse and
heavily compressed history; hyper-connections and conditional memory explained
in prose and equations. No figure quota or decorative duplication.

## Research map

- Official report: architecture, data, compute, evaluations and ablations.
- Pinned weights metadata, configuration and license: exact artifact identity.
- Targeted released inference code: cache and compression contracts.
- Skeptical pass: context-dependent efficiency ratios, parameter accounting,
  nonidentical preview/update artifacts, conditional benchmark claims.

## Budget and checkpoints

One bounded primary-source pass, a separate contradiction/count pass, then
desktop/mobile/theme/export review. Use raw artifacts if website parsing fails.

## Success criteria

Correct compression causality, CSA/HCA differences, mHC motivation, Engram
counting, conditional training/compute disclosures and evaluated context.
Leave unverified details explicit; validate records, site and rendered outputs.

## User-supplied facts

The user requests parallel studies of important public models using the guide.

## Assumptions and decisions

Flash is the representative scale. Pro comparisons retain conditions and are
not silently transferred to Flash. V4.1 gets a separate study.

## Revision 3 coverage audit

User requests a thorough check of figures and important mechanisms for every study. Compare the pinned report (including relevant appendices), targeted code and current page. Record a coverage matrix and figure selection decisions in coverage-audit.md. Add useful licensed source figures or independent diagrams, not a quota. Preserve variant, training/inference, evaluation and licensing boundaries. No commit, push, deployment or model execution. A second source-entailment pass and fresh site/visual/export checks are required.
