# Evidence and presentation review

## Evidence audit, October 17, 2026

- The central assertion is bounded: cloud/generalist planning plus specialist
  perception is demonstrated in computer-use frameworks. It is not claimed to
  be universally better, the dominant architecture, or a guarantee of privacy.
- Reviewed placement separately: OmniTool allows separate parser hardware;
  Agent S3 may use hosted grounding; Phi-Ground's disclosed product integration
  does not establish local inference. S2's principal visual expert was 72B,
  so its complete framework is not described as a compact device deployment.
- ScreenVLM is 316M overall; Granite 165M is its decoder, not the complete model.
  Its 276.4 ms mean uses one H100, vLLM and 128 samples. The web-centric training
  limitation is retained. No result is represented as smartphone latency or
  complete agent task success.
- Current Granite model claims use the authored Hugging Face model card, not
  the deprecated IBM documentation or an autogenerated generic inference widget.
  The model, Docling library and MCP server remain distinct.
- PaddleOCR-VL-1.6's June 2 report retains a separate layout detector and a
  0.9B VLM. It is not a demonstrated cloud-led mobile agent.
- The IntBot recipe's 510 ms FP8 and 762 ms FP16 numbers are median perception
  pipeline measurements, not cloud task time. Its quality discussion compares
  output length rather than establishing full accuracy equivalence, so no
  quality-preservation claim is made. The demonstrated controller is not
  asserted to be cloud hosted.
- LTX generation is distinct from perception. Local inference does not exclude
  optional API generation or cloud text encoding. No wrapper integration or
  benchmark is invented.
- MCP offers schemas and structured results, not semantic truth, safety or
  physical placement guarantees. A client host dispatching calls locally is
  marked as a proposed pattern, not a protocol mandate.
- The result JSON, invoice workflow, evaluation matrix and research agenda are
  explicit proposals. No private project experience or unperformed experiment
  is presented as evidence.
- Source Figure 4 is unchanged and attributed; its incidental screenshot is
  discussed in the visual source record rather than silently relicensed.
