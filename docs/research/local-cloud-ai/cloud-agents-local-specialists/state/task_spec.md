# Cloud Agents & Local Specialists

## Inquiry

How can specialized local perception and generation models extend a cloud-led agent, and which current systems establish the architecture, local deployment, and downstream value?

## Intended reader and use

AI researchers and engineers who understand foundation models and want to design cloud-led agents with local specialist tools.

Learning goal: distinguish the control plane from specialist computation, understand useful tool interfaces, and identify evidence needed to justify a deployment.

## Scope and time boundary

Screen parsing and grounding, document parsing, video perception, local generative tools, orchestration, training and evaluation. Evidence inspected through October 17, 2026.

Evidence boundary: inspected primary papers, official implementations and first-party deployment recipes. Separate complete agent demonstrations, independently deployable building blocks and proposed configurations. No popularity, universal superiority or unmeasured handset performance claim.

## Exclusions

General request routing, decoding cooperation and split inference are covered by the existing overview, not repeated here. No private employer material, production deployment, purchases or new services. No executable agent or runtime integration is requested.
