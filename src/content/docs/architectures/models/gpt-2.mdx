GPT-2 is a useful architectural baseline: one stream reads a text prefix and
produces scores for what comes next. There is no separate encoder or encoder
memory connection in its released language decoder.[^code]

This study uses the 2019 report and OpenAI's released `src/model.py` at commit
`9b63575`. It inspects code rather than running a checkpoint. Selected evidence
checked October 5, 2026.[^report][^code]

## Follow the prediction contract

A causal language model factorizes a sequence into next token conditionals:[^report]

<MathExpression display number="1" tex="p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{\lt t})" />

The released code adds token embeddings and learned position embeddings,
applies repeated blocks, then final LayerNorm and a vocabulary projection
using the token embedding weights. It returns logits; softmax and token
selection are not inside this `model` function.[^code]

The block's attention branch reads normalized input, then adds its result
to the original stream. The FFN does the same with the updated stream:

<MathExpression display number="2" tex="
\begin{aligned}
u &= x+\operatorname{Attention}(\operatorname{LN}_1(x)) \\
h &= u+\operatorname{FFN}(\operatorname{LN}_2(u))
\end{aligned}
" />

This is **pre-normalization**, not the original Transformer's Add then Norm
ordering. The FFN expands width `D` to `4D`, applies the code's GELU
approximation, and projects back to `D`.[^code] The report also describes
normalization and residual initialization changes; the inference file alone
is not a complete training implementation.[^report]

## Read the tensor contract

For batch `B`, current input length `T`, model width `D`, and vocabulary `V`:

| Value | Shape | Meaning |
| --- | --- | --- |
| Token IDs | `B × T` | Current input indices |
| Hidden stream | `B × T × D` | Token features throughout the blocks |
| FFN intermediate | `B × T × 4D` | Expanded per position features |
| Logits | `B × T × V` | Vocabulary scores at each current position |

These are symbolic shape counts from the code, not dimensions of a selected
checkpoint.[^code]

## Cached history: check what is returned

The code accepts `past` keys and values and concatenates them with current
keys and values for attention. Crucially, `present` is formed **before** that
concatenation: it contains this call's new KV tensors, not automatically the
entire accumulated history. The caller must manage cache accumulation.
Position indices are offset by the cached length.[^code]

Caching avoids recomputing previous KV projections; it does not make reading
the retained context free. The [attention page](/architectures/evolution/attention-and-memory/)
separates cache storage from attention execution.

## The transferable lesson

Trace a residual stream, distinguish logits from generation policy, and read
cache input and output semantics in code rather than assuming an API contract.
This page makes no current performance ranking, deployment recommendation,
or claim that GPT-2 is an instruction tuned assistant.
