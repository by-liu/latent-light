From the original Transformer to today's language and vision models, this is
a living map of the releases worth understanding. Start with the milestones,
then choose a model to explore in depth.

The selection covers **56 releases and research milestones**, checked through
**October 9, 2026**. Selection favors established model families and influential research milestones.
It is a reading map, not a complete catalog or a popularity ranking.

To compare ideas across releases, use [Architectural Evolution](/architectures/evolution/).
Its mechanism pages connect memory, position, expert routing, residual paths
and visual interfaces back to these studies. Read a deep dive for the model's
full training recipe, implementation choices and evidence.

## Choose a deep dive

Studies of models with public weights follow the
[Model Deep Dive guide](/about/content-guidance/model-deep-dive-guide/). It connects technical
reports to named artifacts and distinguishes reported findings from inspected
implementation and measured results.

The first collection contains **41 studies**, selected for distinct technical
lessons rather than one page per checkpoint. Each starts with the original
report and Hugging Face links, then highlights and scale. Architecture,
training, inference and evaluation connect to the
inspected sources. Original LLaMA is a historical study with restricted release
terms; public weights elsewhere also have different licenses and access rules.
Each page states its own verification boundary. These are source studies, not
locally reproduced model benchmarks.

Browse related generations under GPT, Llama, Mistral, DeepSeek, Qwen, GLM,
Kimi, Gemma and MiniMax in the sidebar. Single studies stay directly accessible. The reading
paths below connect models by the ideas they teach, across family boundaries.

### Related releases and study boundaries

This is a curated technical collection, not a page for every checkpoint update.
Qwen3 Next, Qwen3.5 and Gemma 3n have useful official technical documentation,
but this expansion did not verify a matching standalone generation report.
See [Qwen3 Next](https://qwen.ai/blog?id=qwen3-next),
[Qwen3.5](https://qwen.ai/blog?id=qwen3.5) and
[Gemma 3n](https://ai.google.dev/gemma/docs/gemma-3n)
for those documentation boundaries. A backbone paper
does not establish a later model's entire vision or alignment recipe.

### Pick a reading path

- **Understand the backbone:** [GPT-2](/architectures/models/gpt-2/),
  [BERT](/architectures/models/bert/), then [T5](/architectures/models/t5/).
- **Follow efficient memory:** [Mistral](/architectures/models/mistral-7b/),
  [DeepSeek-V2](/architectures/models/deepseek-v2/),
  [Mamba](/architectures/models/mamba/), then
  [V4.1-Flash](/architectures/models/deepseek-v4-1-flash/).
- **Connect vision to language:** [CLIP](/architectures/models/clip/),
  [BLIP-2](/architectures/models/blip-2/),
  [LLaVA](/architectures/models/llava/), then
  [Qwen3-VL](/architectures/models/qwen3-vl/).
- **Study reasoning and agents:** [V3](/architectures/models/deepseek-v3/),
  [R1](/architectures/models/deepseek-r1/),
  [Qwen3](/architectures/models/qwen3/), then
  [GLM-5](/architectures/models/glm-5/).

Use [Transformer Foundations](/architectures/foundations/) for the shared
mechanisms and [Architectural Evolution](/architectures/evolution/) to compare
design choices. This overview will grow as new releases add useful contrasts.

<details>
<summary>How we read a model</summary>

Follow the input from its processor through the model to the output. Compare
the report with the released configuration and source code, then examine the
training disclosure and evaluation conditions. Keep missing details visible:
a model name does not establish a checkpoint, a complete recipe, or a
universal performance ranking.

</details>
