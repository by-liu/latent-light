“Efficient attention” can mean faster execution, a smaller record of each
token, fewer positions read, or a different memory altogether. These choices
solve different problems. Start with **what is stored** and **what a query can read**,
then ask how the operation runs.[^flash][^gqa][^mla][^linear]

## Execute the same operator more efficiently

FlashAttention brings tiles of queries, keys, and values into fast on chip
memory, updates softmax statistics incrementally, and avoids materializing
the full score matrix in high bandwidth memory. Backward recomputation replaces
storage of that matrix.[^flash]

It preserves dense softmax attention, subject to numerical differences.
The pairwise arithmetic remains quadratic in sequence length. Kernel speed,
attention workspace, persistent KV cache, and total model memory are distinct
measurements. A kernel improvement is not a proof that the model retains less history.

## Share heads or compress content

**GQA** shares a key head and value head within each query group. MQA uses
one KV group; ordinary MHA uses one per query head. None removes positions
from the retained prefix.[^gqa]

For equal key and value head widths, a local tensor count gives:

<MathExpression display number="1" tex="M_{\mathrm{KV}}=2LBT H_{\mathrm{KV}}d_h s" />

Here L is layer count, B batch size, T retained positions, H<sub>KV</sub>
KV heads, d<sub>h</sub> elements per head, and s bytes per element. This counts
keys and values only, excluding runtime overhead. Reducing KV heads by four
reduces this storage by four, not necessarily latency by four.

**MLA** instead jointly compresses content keys and values into a latent for
each token. DeepSeek-V2 also retains a separate positional key. Suitable
projection absorption allows an optimized implementation to read the latent
without reconstructing every old head representation.[^mla]

## Restrict which history participates

A sliding window changes connectivity: each layer reads a bounded recent
region. Older information can travel through intermediate representations
across depth, but an arbitrarily distant token is not directly visible to
every layer. [Mistral 7B](/architectures/models/mistral-7b/) supplies a concrete
example.[^mistral]

Learned sparse attention adds a different choice. A cheaper indexer selects
history, then the main attention reads selected tokens or blocks. GLM-5 uses
DSA; MiniMax Sparse Attention selects blocks separately for GQA groups.[^glm][^msa]
Selection can reduce expensive reads while leaving growing storage and
indexing work. “Exact attention on selected entries” is not the same operator
as dense attention over every entry.

For compressed and selected history together, continue with
[DeepSeek-V4](/architectures/models/deepseek-v4/) or
[Qwen3.8-Next](/architectures/models/qwen3-8-flash-next/).

## Replace an append-only history with state

The causal linear Transformer writes key and value associations to a matrix.
Using column vectors, a positive feature map φ, and zero initial states:[^linear]

<MathExpression display number="2" tex="\begin{aligned}
S_t &= S_{t-1}+\phi(k_t)v_t^\top\\
z_t &= z_{t-1}+\phi(k_t)\\
y_t^\top &= \frac{\phi(q_t)^\top S_t}{\phi(q_t)^\top z_t}
\end{aligned}" />

The denominator must be nonzero. With feature width d<sub>φ</sub> and value
width d<sub>v</sub>, the state contains d<sub>φ</sub>d<sub>v</sub> + d<sub>φ</sub>
elements, independent of T. This is a different matching operator, not exact
softmax attention in another order.

[Mamba](/architectures/models/mamba/) uses a selective state space model:
input dependent dynamics control what survives and how it is read.[^mamba]
[Kimi Linear](/architectures/models/kimi-linear/) adds corrective writes and
channel specific forgetting. These are distinct update rules, not synonyms
for the additive recurrence above.[^kimi]

## Compare the right budgets

Report quality, prefill latency, decoding latency, persistent state, peak
workspace, total weights, and throughput at a stated concurrency. Control
hardware, precision, lengths, and backend. Inspect retrieval under distance
and distractors, not only easy recent facts.

This is a proposed measurement framework, not a benchmark result. Selected
