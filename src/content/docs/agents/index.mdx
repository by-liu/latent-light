An AI model can describe how to investigate a problem. An agent system can
work through it: choose an action, inspect the result and decide what to do next.
The useful unit is the **whole system: model, harness, tools, environment and
feedback**.[^react]

This collection connects the mechanisms with the systems people actually use.
Choose a route first; the chapters supply the depth.

## A map of the system

The model proposes decisions. The **harness** is the surrounding software that
assembles context, manages the loop and coordinates execution. Persistent
session records and execution environments can have different lifecycles;
they need not live inside one process.[^managed][^api]

A fixed workflow chooses its path in advance. An agent delegates more path
selection to the model. Many useful systems combine both: deterministic steps
handle known work, and a model handles uncertainty.[^patterns] More freedom is
useful only when the system can observe and verify what it does.

## Study the systems

The [deep-dive overview](/agents/deep-dives/) compares the five initial studies
by execution ownership, persistence, extension mechanisms and control. It also
connects them to the [broader ecosystem](/agents/ecosystem/), including frameworks,
SDKs and managed runtimes.

The studies ask different questions. What does Claude Code package into its
workflow? How does Codex expose a controllable session to clients? What does Pi
leave to its host and extensions? What does OpenCode's client/server boundary
make possible? What changes when DeepSeek makes the loop itself a plugin?
Follow a system from its design to its consequences, rather than counting features.

## Follow the frontier

The [frontier discussion](/agents/deep-dives/#frontier) examines durable sessions,
evolving context, coordinated workers and feedback that can genuinely grade
an outcome. Research findings and vendor engineering accounts have different
limits; a documented feature does not establish reliable task completion.

The individual studies identify their inspected documentation or repository
snapshot. Source checks for the five studies are **October 11, 2026**. The
broader directory retains its separately dated checks. These pages explain
implementations and research; they do not report a new head-to-head benchmark.
